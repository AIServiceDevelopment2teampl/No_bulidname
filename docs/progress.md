| 2026-11-11 | AI 점원의 '어울리는 내 옷' 추천은 **상품과 같은 종류만 뺀다** (사용자 선택) | 상의 → 하의·아우터·기타, 하의 → 상의·아우터·기타, 아우터 → 상의·하의·기타, 기타 → 상의·하의·아우터. 시안 7처럼 코트에 운동화도 추천될 수 있다 |
| 2026-11-20 | **게스트는 서버 계정 없이** 쇼핑몰 구경만 하고, 서버 기능 자리에는 로그인 안내를 보여 준다 (사용자 선택) | 게스트에게 서버 임시 계정을 주면 계정을 계속 새로 만들어 사용자당 횟수 제한을 피할 수 있어 학교 Claude 크레딧이 샐 수 있다. 게스트는 서버에 요청하지 않는다 |
