# SP2 팀 MVP 구현 계획 (12조)

- 서비스: 해외 쇼핑몰 상품 정보를 그 자리에서 한국어로 보여 주고, 내 옷장 속 비슷한 옷과 비교해 구매 판단을 돕는 안드로이드 앱 (이름 미정, 후보: ClosetLens, 옷장 AI)
- 팀 GitHub: https://github.com/AIServiceDevelopment2teampl/No_bulidname
- 작성일: 2026-10-28

## 1. MVP 구현 계획 (SP2, 12주차까지)

### 목표
핵심 흐름 하나를 처음부터 끝까지 실제 앱에서 동작시킨다.

> **옷장에 옷 등록 → 해외 쇼핑몰 상품 페이지 열기 → 상품 정보를 한국어로 보기 → 내 옷장에서 비슷한 옷 TOP 3 보기**

그리고 Google Play 스토어 출시를 위해 **11주차 안에 비공개 테스트를 시작**한다 (Play 정책상 테스터 12명 이상이 14일 동안 참여해야 정식 출시 신청 가능).

### 구현할 기능
| # | 기능 | 설명 | 주차 |
|---|------|------|------|
| 1 | 옷 사진 등록·자동 분류 | 사진을 올리면 CLIP(사전학습 이미지 모델)이 종류(상의·하의·아우터)와 색을 분류한다. 틀리면 사용자가 고친다 | 9~10 |
| 2 | 옷장 조회·수정·삭제 | 사진 격자 목록, 종류·색 필터, 상세 보기, 수정, 삭제 | 9~10 |
| 3 | Google 로그인·계정 삭제 | 폰을 바꿔도 옷장 유지. Play 정책에 따라 앱 안과 웹에서 계정·데이터 삭제 지원 | 10~11 |
| 4 | 유사 의류 검색 | 상품 이미지와 내 옷 사진을 CLIP으로 임베딩하고 FAISS로 같은 종류 안에서 TOP 3를 찾는다 | 10 |
| 5 | 단위 변환 | 인치→cm, 파운드→kg. 원문을 함께 표시한다 (예: `76.2 cm (30 in)`) | 10 |
| 6 | 상품 정보 구조화·번역 | 상품 페이지에서 상품명·색·소재·핏·사이즈·세탁 정보를 뽑아 한국어로 보여 준다. 원문에 없는 정보는 `정보 없음` | 11 |
| 7 | 홈·쇼핑몰 목록·인앱 브라우저 | 지원 쇼핑몰을 앱 안 브라우저(WebView)로 연다. 주소 직접 입력, 쇼핑몰마다 한국 배송 태그(`배송 가능`/`배송대행 필요`/`그 외`) | 11 |
| 8 | 비공개 테스트 출시 | 첫 빌드를 Play Console 비공개 테스트에 올리고 테스터 참여 시작 | 11 |
| (도전) | 페이지 그 자리 번역 | 페이지 글자 전체를 한국어로 바꿔 보여 준다 (구글 웹 번역 방식). 위험이 커서 SP2에서는 도전 목표로 두고, 안 되면 6번(상품 정보 번역)만 시연한다 | 11~12 |

### 기술 구성
| 구분 | 선택 |
|------|------|
| 앱 | Kotlin + Jetpack Compose (minSdk 26, targetSdk 36), Room, Retrofit |
| 서버 | Python + FastAPI, SQLite, FAISS |
| AI | CLIP (분류·임베딩, 미세조정 없음), Claude API Haiku 5.5 (번역·상품 정보 정리) |
| 서버 호스팅 | Vultr 서울 리전 (선불 크레딧) |
| 테스트 | pytest (서버), Node + jsdom (주입 스크립트), JUnit·Compose UI 테스트 (앱) |

### 지원 쇼핑몰 (한국어를 지원하지 않는 해외 쇼핑몰)
- 영어: ASOS, Urban Outfitters, Abercrombie & Fitch, END. Clothing, J.Crew, Nordstrom, 유니클로 미국
- 일본어: ZOZOTOWN, 유니클로 일본, GU 일본, BEAMS
- 상품 페이지 구조를 확인한 곳: ASOS·ZOZOTOWN(표준 상품 데이터 JSON-LD 있음), 유니클로 일본(페이지 내부 데이터). 나머지는 실제 폰에서 확인 후 기본 목록 확정

### RISK 관리 계획
| 위험 | 영향 | 대응 |
|------|------|------|
| **Play 스팸 정책 (WebView).** 남의 웹사이트를 WebView로 감싸는 것이 주목적인 앱은 금지 | 심사 거절 | 옷장·비교가 주목적임을 화면과 스토어 설명에 분명히 한다. 특정 쇼핑몰 전용이 아닌 일반 브라우저처럼 주소 입력 지원. 첫 비공개 테스트 빌드는 옷장 기능 위주로 올리는 방안 검토. 거절되면 공유하기·스크린샷 경로로 출시 |
| **비공개 테스트 14일 조건** | 15주차 정식 출시 불가 | 11주차 안에 첫 빌드 업로드. 테스터 15명 이상을 미리 모은다 |
| **쇼핑몰 봇 차단.** 확인 결과 ASOS·ZOZOTOWN은 서버에서 페이지를 직접 받으면 403 차단 | 상품 정보 수집 실패 | 서버가 아니라 앱 안 WebView(실제 브라우저)에서 주입 스크립트로 읽는 구조로 설계함 |
| 사이트마다 상품 데이터 형식이 다름 | 상품 정보 누락 | 공통 순서로 읽는다: ① 표준 데이터(JSON-LD) ② `og:` 태그·페이지 데이터 ③ 페이지 글자를 LLM으로 정리 |
| CLIP 분류·검색 정확도 부족 | 잘못된 분류·추천 | 라벨링한 의류 사진 100장으로 측정(목표 정확도 85%, Recall@3 80%). 부족하면 사용자 수정 화면으로 보완하고 패션 특화 CLIP 비교. 이후 AI Hub K-Fashion 데이터로 분류층만 학습 |
| LLM 비용·속도 | 예산 초과, 느림 | 가장 싼 모델(Haiku) 사용, 번역 결과 캐시, 화면에 보이는 부분부터 처리. API 키는 서버에만 둔다 |
| 서버 메모리 (CLIP) | 서버 다운 | 배포 전에 메모리 사용량을 재고 요금제 결정 (4GB 예정) |
| 사이즈 환산 오차 | 잘못된 구매 | 원문 병기, '참고용' 표시, 페이지의 브랜드 사이즈표 우선 |
| 일정 지연 | SP2 시연 불가 | 기능 번호 순으로 개발하고, 늦어지면 1·2·4·6번(핵심 흐름)만으로 시연. 각 기능은 완료 조건 테스트를 먼저 쓰고 통과해야 완료로 본다 |

## 2. 완성본 구현 계획 (15주차 및 그 이후)

### 15주차까지
| 기능 | 설명 |
|------|------|
| 페이지 그 자리 번역 | 영어·일본어 필수, 그 밖의 언어는 자동 감지로 가능한 만큼 |
| 해외 사이즈 → 한국 사이즈 변환 | 브랜드 사이즈표 기준, 원문 병기 |
| 구매 전 비교 리포트 | 내 옷과 비교해 비슷한 점 / 다른 점 / 확인 안 된 점을 정리. 구매를 권하거나 막는 단정은 하지 않는다 |
| AI 점원 | 화면을 가리지 않는 패널. 상품 질문 답변("세탁기 돌려도 돼?"), 비교 리포트 전달, "이 옷과 어울리는 내 옷" 추천 |
| 공유하기로 상품 받기 | 다른 쇼핑 앱에서 공유한 스크린샷을 OCR로 분석해 같은 비교 결과 제공 |
| 옷 자동 등록 | 주문내역 캡처로 여러 벌 한 번에 등록, 앱에서 산 옷 자동 감지("옷장에 추가할까요?"), 영수증 사진 등록. 사진을 하나씩 찍어 올리는 부담을 없앤다 |
| 내 쇼핑몰 추가 | 사용자가 목록에 없는 쇼핑몰을 직접 추가 |
| **Google Play 정식 출시** | 비공개 테스트 → 프로덕션, AI 서버 배포, 사용자 평가 |

### 그 이후 (야심찬 목표)
| 기능 | 설명 |
|------|------|
| 체형 맞춤 추천 | 키·몸무게·체형과 상품 사이즈표로 사이즈를 계산하고, 핏 조언은 LLM이 설명 |
| 패션 특화 모델 | AI Hub K-Fashion 데이터(120만 장)로 색·핏·기장·스타일(23종) 분류층 학습. 스타일 분류를 코디 추천 근거로 사용 |
| 예상 총액 계산 | 상품가 + 배송비 + 관세·부가세(면세 한도 반영)를 '참고용'으로 표시, 배송대행지 안내 |
| 이미지 속 글자 번역 | 이미지로 된 사이즈표 번역 |
| 코디 추천·착용 통계 | 옷장 전체로 코디 조합 추천, 자주 안 입는 옷 알림 |
| 등록 경로 확장 | 주문확인 이메일 연동 자동 등록 |
| 플랫폼 확장 | iOS |
| 사업화 아이디어 | 배송대행 업체 연결(제휴 수수료) |

### 성공 지표 (목표치)
| 항목 | 목표 |
|------|------|
| 옷 종류 분류 정확도 | 85% 이상 (라벨링한 의류 100장) |
| 유사 의류 검색 Recall@3 | 80% 이상 |
| 상품 정보 추출 필수 필드 정확도 | 90% 이상 (상품 페이지 30~50개) |
| 번역 가독성 | 사용자 평가 5점 척도 평균 4점 이상 |
| 비교 결과 표시 속도 | 중앙값 10초 이내 |
