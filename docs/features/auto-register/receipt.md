# 기능: 영수증 사진 등록

## 설명
오프라인 매장 영수증 사진을 올리면 의류 품목을 뽑아 등록한다. 영수증에는 보통 상품명·품번·가격만 있고 옷 사진이 없으므로, 등록된 옷은 `사진 필요` 상태가 되고 유사 검색에서 빠진다. 사용자가 나중에 사진을 붙이면 검색 대상이 된다.

일정이 부족하면 이 기능은 후속으로 미룬다 (자동 등록 중 우선순위 3번째).

## 입력
- 영수증 사진 1장

## 출력
- 등록 후보: 상품명, 품번, 가격, 매장, 구매일, 의류 여부
- 확인 후 옷장 항목 (source=`receipt`, image 없음)

## 예외 상황
- 쇼핑백·포장비 등 의류가 아닌 줄: 후보에서 뺀다
- 카드 번호 일부·승인번호 등 결제 정보: 저장하지 않는다
- 상품명이 약어라 종류를 모름: category=`other`, 사용자에게 고르게 한다
- 영수증이 흐림: "영수증 글자가 잘 보이게 다시 찍어 주세요"
