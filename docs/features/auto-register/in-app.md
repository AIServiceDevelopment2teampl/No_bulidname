# 기능: 앱에서 산 옷 자동 등록

## 설명
인앱 브라우저에서 결제를 마치면 주문 완료 페이지를 알아채고 "옷장에 추가할까요?" 카드를 띄운다. 한 번 누르면 등록된다.

1. `order.js`가 주문 완료 페이지를 감지한다 (사이트별 URL 패턴 + 페이지 글자)
2. 주문 상품 영역에서 상품명, 색상, 사이즈, 가격, 이미지 URL을 읽는다
3. 이번 쇼핑 중 본 상품(products)과 맞춰 보고, 맞으면 그 정보로 빈 칸을 채운다
4. 확인 카드 → 사용자가 고른 것만 저장 (source=`in_app`)

## 입력
- 주문 완료 페이지의 상품 영역 데이터
- 이번 쇼핑에서 분석한 상품 목록

## 출력
- 등록 후보 → 확인 후 옷장 항목

## 예외 상황
- 이름·주소·연락처·결제수단: 읽지도, 서버로 보내지도 않는다 (상품 영역만 읽음)
- 감지 규칙이 없는 사이트: 아무것도 하지 않는다. 대신 주문내역 캡처 등록을 안내할 수 있다
- 의류가 아닌 상품: 기본 체크 해제
- 새로고침 등으로 같은 주문 페이지를 다시 봄: 주문번호로 중복을 막는다
- 사용자가 카드를 닫음: 저장하지 않는다

## 완료 조건
- [ ] [주입JS] 고정 주문 완료 HTML에서 상품 N개가 정확히 추출된다
- [ ] [주입JS] 같은 HTML의 이름·주소·카드 번호 영역 글자가 추출 결과에 없다
- [ ] [주입JS] 주문 완료가 아닌 페이지(장바구니 등)에서는 감지되지 않는다
- [ ] [서버] 확인 전에는 저장되지 않는다
- [ ] [서버] 같은 주문번호는 두 번 등록되지 않는다
- [ ] [서버] 본 상품과 일치하면 그 상품의 이미지·속성이 옷 항목에 채워진다
- [ ] [수동] 지원 쇼핑몰 1곳 이상에서 실제 주문(또는 주문 완료 페이지 저장본)으로 동작을 확인한다
