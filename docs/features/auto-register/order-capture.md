# 기능: 주문내역 캡처로 일괄 등록

## 설명
다른 쇼핑몰·쇼핑 앱의 **주문내역 화면 캡처**를 올리면 여러 벌을 한 번에 등록한다. 옷을 하나씩 찍는 부담을 줄이는 주 등록 경로다.

1. 캡처 업로드 (여러 장 가능)
2. OCR로 글자를 읽고, LLM이 상품 줄을 나눈다: 상품명, 옵션(색상·사이즈), 가격, 주문일
3. 캡처 안의 상품 썸네일 영역을 잘라 옷 이미지로 쓴다 (CLIP 임베딩·분류)
4. 확인 화면에서 사용자가 등록할 옷을 고르고 고친다
5. 고른 것만 옷장에 저장한다 (source=`order_capture`)

## 입력
- 주문내역 스크린샷 1장 이상

## 출력
- 등록 후보 목록 (imports.candidates): 상품명, 색상, 사이즈, 가격, 썸네일, 의류 여부, 종류
- 확인 후 옷장 항목

## 예외 상황
- 의류가 아닌 상품 (화장품, 생활용품): 후보에는 보여 주되 기본 체크를 해제한다
- 썸네일을 못 찾거나 너무 작음: 이미지 없이 등록하고 `사진 필요` 표시 (유사 검색에서 빠짐)
- 같은 주문을 다시 올림: 주문번호나 상품명·날짜 조합이 같으면 "이미 등록된 옷이에요"
- 주문자 이름·주소·연락처: 후보에 넣지 않고 서버에 저장하지 않는다
- 글자를 거의 못 읽음: "주문내역이 잘 보이게 다시 캡처해 주세요"

## 완료 조건

- [ ] [서버] 같은 주문을 두 번 확인해도 옷이 두 번 생기지 않는다

- [ ] [서버] 썸네일이 있는 후보는 임베딩이 만들어지고, 없는 후보는 만들어지지 않는다
