# 기능: 구매 전 비교 리포트

## 설명
구매를 고민 중인 상품과 유사 의류 TOP 3의 속성을 비교해 세 부분으로 정리한다.

- **비슷한 점:** 양쪽에 같은 정보가 있고 값이 비슷한 것 (예: 둘 다 검정 니트)
- **다른 점:** 양쪽에 정보가 있고 값이 다른 것 (예: 면 혼방 vs 울)
- **확인 안 된 점:** 한쪽이라도 정보가 없는 것 (예: 기존 옷의 소재 정보 없음)

LLM은 이미 정리된 속성을 문장으로 다듬는 데만 쓴다. 비교 근거는 데이터에 있는 값뿐이다. 리포트는 AI 점원 패널과 분석 화면에 보여 준다.

## 입력
- 상품 정보 (products.fields)
- 유사 의류 TOP 3와 각 옷의 속성, 이미지 유사도

## 출력
- reports 행: `similar[]`, `different[]`, `unknown[]` (각 항목에 근거 필드명 포함)
- 화면: 위에 상품, 아래에 기존 옷 TOP 3, 그 아래 세 부분 설명

## 예외 상황
- 유사 의류가 없음: "옷장에 비슷한 옷이 없어요" 리포트 (확인 안 된 점에 상품 정보만 정리)
- LLM 문장에 구매를 권하거나 막는 단정 표현이 있음 (예: "사세요", "사지 마세요", "중복 구매 확률"): 그 문장을 빼고 로그를 남긴다
- LLM 실패: 속성 비교표만 보여 준다 (문장 없이)

## 완료 조건
- [ ] [서버] 출력이 세 부분 JSON 형식을 따른다
- [ ] [서버] 기존 옷의 소재가 `null`이면 소재 비교는 `unknown`에 들어간다 (LLM 없이 정해지는 규칙)
- [ ] [서버] 양쪽 값이 같은 필드는 `similar`, 다른 필드는 `different`에 들어간다
- [ ] [서버] LLM 가짜가 금지 표현을 넣으면 해당 문장이 빠진다
- [ ] [서버] 유사 의류 0개일 때 "비슷한 옷이 없어요" 리포트가 나온다
- [ ] [서버] LLM이 실패해도 비교표는 나온다
