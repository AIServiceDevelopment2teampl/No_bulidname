# 기능: 유사 의류 검색

## 설명
구매를 고민 중인 상품의 이미지를 CLIP으로 임베딩하고, 내 옷장 임베딩과 코사인 유사도를 비교해 가장 비슷한 옷 TOP 3를 돌려준다. 같은 종류(상의끼리, 하의끼리) 안에서 먼저 찾는다.

점수는 **이미지 유사도**로만 표기한다. '중복 구매 확률', '같은 제품'처럼 표현하지 않는다.

## 입력
- 상품 id (상품 이미지와 category가 들어 있음)
- 상품 이미지가 여러 장이면 사용자가 고른 이미지, 기본은 대표 이미지

## 출력
- 최대 3개: cloth_id, 이미지, 속성, 이미지 유사도 점수 (내림차순)
- 결과 상태: `ok` / `empty_closet` / `no_similar` (모두 기준 점수 미만)

## 예외 상황
- 옷장이 비어 있음: `empty_closet`, 앱은 등록 안내
- 상품 category를 모름: 전체 옷장에서 찾는다
- 같은 종류 옷이 3개 미만: 있는 만큼만 돌려준다
- 사진 없는 옷(영수증 등록 등): 검색 대상에서 빠진다
- 상품 이미지를 받지 못함: 400, "상품 사진을 찾지 못했어요"

## 완료 조건
- [ ] [서버] 옷장에 상품과 같은 이미지가 있으면 1위로 나온다
- [ ] [서버] 결과는 최대 3개이고 점수 내림차순이다
- [ ] [서버] 상품이 상의면 하의·아우터는 나오지 않는다 (category를 알 때)
- [ ] [서버] 옷장이 비면 빈 결과와 `empty_closet`
- [ ] [서버] 다른 사용자의 옷은 결과에 나오지 않는다
- [ ] [서버] 사진 없는 옷은 결과에 나오지 않는다
- [ ] [서버] 응답과 앱 화면 어디에도 '확률'이라는 표현이 없다
- [ ] [평가] 테스트 옷장과 사람이 고른 정답 세트로 Recall@3을 재고 progress.md에 기록한다 (목표 80%). `no_similar` 기준 점수도 이 평가로 정한다
