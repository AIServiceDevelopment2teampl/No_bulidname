# 기능: AI 점원

## 설명
옷에 관심이 적거나 고르는 법을 잘 모르는 사용자를 위한 쇼핑 도우미. 인앱 브라우저 화면 가장자리의 작은 버튼을 누르면 아래쪽 절반 패널로 열린다(초안). 위쪽에서는 쇼핑 페이지가 계속 보인다.

MVP 범위:
1. **상품 질문 답변:** 지금 보고 있는 상품에 대해 묻고 답한다 ("세탁기 돌려도 돼?", "이거 두꺼워?"). 답은 상품 정보에 있는 내용만 근거로 한다.
2. **비교 리포트 전달:** 상품 페이지에 들어가면 버튼에 "비슷한 옷 N벌 있어요" 알림을 띄우고, 패널을 열면 TOP 3와 리포트를 먼저 보여 준다.
3. **간단 추천:** "이 옷과 어울리는 내 옷"을 옷장에서 1~3개 고른다 (상품이 상의면 하의·아우터 중에서).

전체 코디 조합 추천, 새 상품 추천은 후속이다.

## 입력
- 사용자 질문 (글자)
- 현재 상품 정보, 유사 의류·리포트, 사용자 옷장 목록(속성)
- 대화 기록 (상품별)

## 출력
- 답변 글
- 추천 시 옷 카드 (옷장에 실제로 있는 옷만)

## 예외 상황
- 상품 정보에 없는 내용을 물음: "페이지에 그 정보가 없어요"라고 답하고 지어내지 않는다
- 상품 페이지가 아닌 곳에서 엶: 일반 쇼핑 질문만 받고, 상품 비교 기능은 "상품 페이지에서 눌러 주세요"
- 옷장이 비어 있음: 추천 대신 등록 안내
- LLM이 옷장에 없는 옷 id를 추천함: 걸러 내고, 남는 게 없으면 "어울리는 옷을 찾지 못했어요"
- 구매를 권하거나 막는 단정 표현: 비교 리포트와 같은 규칙으로 뺀다

## 완료 조건
- [ ] [서버] 추천 결과의 옷 id가 모두 해당 사용자 옷장에 있다 (LLM 가짜가 없는 id를 내도 걸러진다)
- [ ] [서버] 상품이 상의일 때 추천에 상의가 없다
- [ ] [서버] 옷장이 비면 추천 대신 등록 안내를 돌려준다
- [ ] [서버] 대화 기록이 상품별로 저장되고 다시 불러와진다
- [ ] [서버] LLM에 보내는 내용에 상품 정보와 옷장 속성만 들어가고 주문자 정보 등은 없다
- [ ] [앱] 패널을 열고 닫아도 웹페이지 스크롤 위치가 그대로다
- [ ] [평가] 상품 정보에 답이 없는 질문 20개에서 지어낸 답의 수를 세어 progress.md에 기록한다 (목표 0개)
