# 기능: Google 로그인·계정 삭제

## 설명
사용자는 Google 계정으로 로그인한다. 폰을 바꾸거나 앱을 다시 설치해도 같은 옷장을 쓸 수 있다.
앱이 Google ID 토큰을 받아 서버로 보내면, 서버가 토큰을 검증하고 자체 세션 토큰을 돌려준다. 이후 모든 요청은 세션 토큰으로 사용자를 구분한다 (초안).

**Play 정책:** 앱에서 계정을 만들 수 있으면 **앱 안**과 **웹 페이지** 두 곳에서 계정 삭제를 요청할 수 있어야 한다. 웹 페이지 주소는 Play Console 데이터 보안 양식에 적는다.

## 입력
- 앱: Google 계정 선택 (Android Credential Manager)
- 서버 `POST /v1/auth/google`: Google ID 토큰
- 계정 삭제: 앱 마이 화면의 `계정 삭제` 버튼, 또는 웹 삭제 요청 페이지

## 출력
- 로그인: 서버 세션 토큰, 사용자 id. 앱은 세션 토큰을 기기에 암호화해 저장한다
- 계정 삭제: 사용자 행과 그 사용자의 옷·이미지·임베딩·대화·등록 후보를 모두 지운다

## 예외 상황
- 사용자가 계정 선택을 취소: 로그인 화면에 그대로 둔다
- 위조·만료된 Google ID 토큰, 우리 앱용이 아닌 토큰(aud 불일치): 401
- 세션 토큰이 없거나 만료: 401. 앱은 로그인 화면으로 보낸다
- 네트워크 오류: 다시 시도 버튼
- 다른 사용자의 옷 id로 요청: 404 (있는지 없는지 알려 주지 않는다)

## 완료 조건
- [ ] [서버] 올바른 Google ID 토큰이면 사용자가 만들어지고 세션 토큰을 돌려준다 (Google 검증은 가짜로 바꿔 테스트)
- [ ] [서버] 같은 Google 계정으로 다시 로그인하면 새 사용자를 만들지 않고 같은 id를 돌려준다
- [ ] [서버] 위조·만료·aud 불일치 토큰은 401이다
- [ ] [서버] 세션 토큰 없이 `/v1/clothes` 등을 부르면 401이다
- [ ] [서버] 사용자 A의 세션으로 사용자 B의 옷을 읽거나 지울 수 없다
- [ ] [서버] `DELETE /v1/me` 후 그 사용자의 DB 행·이미지 파일·임베딩이 남지 않는다
- [ ] [앱] 로그인하지 않았으면 로그인 화면이 뜨고, 로그인하면 홈으로 간다 (Compose UI 테스트, 서버는 가짜)
- [ ] [앱] 마이 화면에서 계정 삭제를 확인하면 서버에 삭제를 요청하고 로그인 화면으로 돌아간다
- [ ] [수동] 웹 계정 삭제 요청 페이지를 게시하고 Play Console에 주소를 적는다
