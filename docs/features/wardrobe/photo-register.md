# 기능: 옷 사진 등록·자동 분류

## 설명
사용자가 카메라나 갤러리로 옷 사진을 올리면, 서버가 CLIP으로 종류(상의·하의·아우터·기타)와 색을 자동 분류하고 임베딩을 저장한다. 옷은 `미확인` 상태로 만들어지고, 사용자가 분류를 확인하거나 고치면 `확인됨`이 된다.

자동 등록(주문내역 캡처·앱 내 구매·영수증)이 주 경로이고, 이 기능은 마지막 수단이다. 다만 옷장·임베딩·분류의 기반이므로 가장 먼저 만든다.

## 입력
- 이미지 1장 이상 (JPG, PNG, WebP). 1장에 옷 1벌.
- 앱: 카메라 촬영 또는 갤러리 선택 (여러 장 선택 가능)

## 출력
- 옷 항목: id, 이미지, category, color, source=`photo`, confirmed=false
- 임베딩 1개 (clothes_embeddings)
- 앱: 분류 결과 확인 화면 → 고치거나 그대로 저장

## 예외 상황
- 이미지가 아니거나 깨진 파일: 400, "이미지를 읽을 수 없어요"
- 파일이 너무 큼 (상한은 구현 때 정함): 413
- 같은 사진(해시 동일)을 다시 올림: 저장하지 않고 "이미 등록된 사진이에요"와 기존 옷 id를 돌려준다
- 분류 신뢰도가 낮음: category=`other`로 두고 앱에서 "종류를 골라 주세요"로 표시
- 서버 연결 실패: 앱에서 다시 시도 버튼
