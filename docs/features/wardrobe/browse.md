# 기능: 옷장 조회·수정·삭제

## 설명
등록된 옷을 사진 격자로 보여 주고 종류·색으로 거른다. 옷을 눌러 상세를 보고 속성을 고치거나 지운다. 마이 탭에서 내 데이터 전체를 지울 수 있다.

## 입력
- 목록: 필터(category, color), 페이지
- 수정: category, color, name, brand, material, size 중 바꿀 값
- 삭제: 옷 id, 또는 전체 삭제 요청

## 출력
- 목록: 옷 배열 (이미지 URL, 속성, confirmed, source). `미확인`, `사진 필요` 표시용 값 포함
- 수정: 바뀐 옷. 수정하면 confirmed=true
- 삭제: 성공 여부

## 예외 상황
- 다른 사용자의 옷 id로 조회·수정·삭제: 404 (있는지 여부도 알려 주지 않음)
- 정해진 목록 밖의 category·color로 수정: 400
- 옷장이 비어 있음: 빈 배열. 앱은 "주문내역 캡처로 한 번에 등록해 보세요" 안내
- 오프라인: 앱은 Room에 저장된 마지막 목록을 보여 주고 수정·삭제는 막는다

## 완료 조건
- [ ] [서버] category·color 필터 결과에 조건과 다른 옷이 없다
- [ ] [서버] 수정하면 값이 바뀌고 confirmed=true가 된다
- [ ] [서버] 잘못된 category 값으로 수정하면 400
- [ ] [서버] 삭제하면 DB 행, 이미지 파일, 임베딩이 모두 사라지고 유사 검색 결과에도 나오지 않는다
- [ ] [서버] 전체 삭제 후 해당 사용자의 옷·상품·리포트·대화·등록 기록이 0건이다
- [ ] [서버] 다른 사용자의 옷에 접근하면 404
- [ ] [앱] 필터를 바꾸면 목록이 바뀐다 (Compose UI 테스트, 서버는 가짜)
