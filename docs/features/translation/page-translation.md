# 기능: 페이지 그 자리 번역

## 설명
인앱 브라우저로 연 해외 쇼핑몰 페이지의 글자를 그 자리에서 한국어로 바꾼다 (구글 웹 번역 방식). 화면 캡처나 OCR 없이 페이지의 글자를 직접 읽는다.

1. 주입 스크립트 `translate.js`가 화면에 보이는 텍스트 노드를 모은다.
2. 앱이 서버 `/v1/translate`로 문장 배열을 보낸다.
3. 서버는 캐시에 없는 문장만 번역하고 단위 변환([unit-conversion.md](unit-conversion.md))을 붙인다.
4. 스크립트가 원래 글자를 번역문으로 바꾼다.
5. 스크롤·더 보기로 새로 생긴 글자도 같은 방식으로 번역한다 (MutationObserver).

영어·일본어는 필수 지원이고, 그 밖의 언어는 자동 감지로 가능한 만큼 지원한다.

## 입력
- 서버: 문장 배열, 원문 언어(모르면 자동 감지), 대상 언어 `ko`
- 앱: 번역 켜기/끄기 토글, 원문 보기

## 출력
- 서버: 입력과 같은 길이·순서의 번역 배열
- 화면: 번역된 페이지. 원문 보기를 누르면 원래 글자로 돌아간다

## 예외 상황
- `input`, `textarea`, 비밀번호 칸, `script`, `style`: 건드리지 않는다
- 로그인·결제 페이지(URL 패턴 목록): 글자를 모으지도, 서버로 보내지도 않는다
- 이미 한국어인 문장: 번역하지 않는다
- 서버 오류·시간 초과: 원문을 유지하고 "번역하지 못했어요" 알림을 띄운다
- 숫자·가격·상품 코드만 있는 글자: 번역하지 않는다
