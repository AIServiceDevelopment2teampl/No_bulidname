# 기능: 단위·사이즈 변환

## 설명
해외 상품 정보의 단위를 한국식으로 바꿔 원문과 함께 보여 준다. 페이지 번역과 상품 정보 구조화가 이 기능을 쓴다. 정해진 계산과 표만 쓰는 순수 함수라 LLM을 쓰지 않는다.

- 길이: inch(`in`, `"`) → cm, feet → cm
- 무게: lb → kg, oz → g
- 신발 사이즈: US·UK·EU → mm (환산표)
- 의류 사이즈: US·UK·EU·JP → 한국 사이즈 (환산표, 남녀 구분)

## 입력
- 문자열 (예: `32 in`, `32"`, `30-32 in`, `32 1/2 in`, `1.5 lb`, `US M 9`)
- 의류·신발 사이즈는 성별·종류 정보가 있으면 함께

## 출력
- 변환 결과와 원문 (예: `81.3 cm (32 in)`)
- 반올림 규칙 (초안): 사사오입. cm는 소수 첫째 자리, kg는 소수 둘째 자리, g는 정수
- 사이즈 환산은 `참고용` 표시를 붙인다

## 예외 상황
- 모르는 단위·형식: 바꾸지 않고 원문 그대로 둔다
- 페이지에 브랜드 사이즈표가 있으면 일반 환산표보다 그 표를 우선한다 (상품 정보 구조화에서 처리)
- 성별을 모르는 의류 사이즈: 환산하지 않고 원문만 보여 준다

## 완료 조건
- [ ] `32 in` → `81.3 cm (32 in)` (1 in = 2.54 cm)
- [ ] `32"` 표기도 같은 결과
- [ ] 범위 `30-32 in` → `76.2-81.3 cm (30-32 in)`
- [ ] 분수 `32 1/4 in` → `81.9 cm (32 1/4 in)`
- [ ] 반올림 경계값은 올린다: 82.55 → `82.6` (부동소수점 오차 없이 Decimal 사사오입)
- [ ] `1.5 lb` → `0.68 kg (1.5 lb)` (1 lb = 0.45359237 kg)
- [ ] `8 oz` → `227 g (8 oz)` (1 oz = 28.349523125 g)
- [ ] 신발·의류 사이즈 결과가 환산표 파일의 값과 같고 `참고용` 표시가 붙는다
- [ ] 모르는 단위는 원문이 그대로 나온다
- [ ] 문장 안에 섞인 단위도 찾아서 바꾼다 (예: `Length: 28 in, Chest: 21 in`)
