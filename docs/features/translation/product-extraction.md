# 기능: 상품 정보 구조화

## 설명
상품 페이지(인앱 브라우저) 또는 상품 캡처(공유하기)에서 구매에 필요한 정보를 뽑아 한국어 카드로 정리한다.

- 필드: 상품명, 종류(상의·하의·아우터·기타), 색상, 소재, 핏, 사이즈(옵션·치수), 세탁, 가격
- 각 필드는 한국어 값과 **원문**을 함께 저장한다.
- 원문에 없는 정보는 `null`로 두고 화면에는 `정보 없음`으로 표시한다. 사진만 보고 소재나 치수를 추측하지 않는다.

**상품 페이지 감지 (`product.js`):** JSON-LD `@type: Product` → OpenGraph `og:type=product` → 사이트별 규칙 순서로 확인한다.

**추출 순서:** JSON-LD·OpenGraph의 구조화 데이터를 먼저 쓰고, 빠진 필드만 LLM이 본문 글자에서 찾는다.

## 입력
- 인앱 브라우저: URL, JSON-LD·OpenGraph 데이터, 상품 영역 본문 글자, 상품 이미지 URL
- 공유하기: 스크린샷 OCR 결과 글자와 스크린샷 이미지 ([shopping/share-intake.md](../shopping/share-intake.md))

## 출력
- products 행: 필드별 `{ko, original}` 또는 `null`, 원문 언어, 대표 이미지
- 치수가 있으면 단위 변환값 병기
- 앱: `상품명 / 색상 / 소재 / 핏 / 사이즈 / 세탁` 카드, 각 카드에 원문 보기

## 예외 상황
- 상품 페이지가 아님 (목록·검색 페이지): 감지하지 않는다
- LLM이 원문에 없는 값을 만들어 냄: **근거 검사**로 버린다. 각 필드의 `original`이 입력 글자 안에 실제로 있어야 저장한다
- 상품 이미지가 없음: 정보 카드만 만들고 유사 검색은 "상품 사진을 찾지 못했어요"
- 여러 색상 옵션: 사용자가 선택한 옵션이 있으면 그것, 없으면 옵션 목록 전체를 원문 그대로 둔다
