# 기능: 홈·쇼핑몰 목록·인앱 브라우저

## 설명
- **홈:** `쇼핑하기`와 `내 옷장` 진입 카드. 하단 탭 홈 / 내 옷장 / 번역(쇼핑) / 마이.
- **쇼핑몰 목록:** `쇼핑하기`를 누르면 지원 해외 쇼핑몰 목록이 뜬다. 목록은 서버 설정 파일(`/v1/shops`)에서 받아, 앱을 업데이트하지 않고도 바꿀 수 있다.
- **인앱 브라우저:** 고른 쇼핑몰을 Android WebView로 연다. 주소 직접 입력도 된다. 주입 스크립트(번역·상품 감지·주문 감지)를 페이지마다 넣는다.
- **내 쇼핑몰 추가:** 사용자가 목록에 없는 쇼핑몰을 이름과 주소로 직접 추가·삭제할 수 있다. 브라우저에서 보고 있는 사이트를 "목록에 추가"로 넣을 수도 있다. 추가한 쇼핑몰은 앱(Room)에만 저장하고, 기본 목록 아래에 따로 보여 준다. 사이트별 규칙이 없으므로 상품 정보는 공통 순서(JSON-LD → `og:` 태그 → 페이지 글자를 LLM으로 정리)로 읽는다.

**Play 정책 대응:** 남의 웹사이트를 WebView로 감싸는 것이 주목적인 앱은 스팸 정책 위반이다. 그래서 브라우저는 특정 쇼핑몰 전용이 아닌 일반 브라우저처럼 만들고, 화면 곳곳에서 옷장·비교 기능이 중심임을 드러낸다. 쇼핑몰 목록은 로고 대신 텍스트 이름으로 보여 준다(초안).

## 입력
- 쇼핑몰 선택, 또는 주소 입력
- 내 쇼핑몰 추가: 이름, 주소 (또는 현재 보고 있는 페이지)
- 브라우저 조작: 뒤로·앞으로·새로고침, 번역 켜기/끄기, AI 점원 버튼, 외부 브라우저로 열기

## 출력
- 쇼핑몰 목록 (이름, URL, 언어)
- 페이지 표시 + 주입 스크립트 동작

## 예외 상황
- 페이지 로드 실패: 오류 화면과 다시 시도·외부 브라우저로 열기 버튼
- WebView에서 막히는 로그인 (예: Google 계정 로그인): "외부 브라우저로 열기" 안내
- `http://` 주소, 앱 실행 링크(`intent://` 등): 그대로 열지 않고 사용자에게 묻는다
- 쇼핑몰 목록을 받지 못함: 앱에 넣어 둔 기본 목록을 쓴다
- 내 쇼핑몰 추가: `https://`가 아닌 주소, 이미 있는 주소는 받지 않는다. 로그인·결제 페이지 규칙(주입하지 않음)은 추가한 쇼핑몰에도 똑같이 적용한다

## 완료 조건
- [ ] [서버] `/v1/shops`가 설정 파일의 쇼핑몰을 그대로 돌려준다
- [ ] [앱] 쇼핑몰을 누르면 해당 URL로 브라우저 화면이 열린다 (Compose UI 테스트)
- [ ] [앱] 로드 실패 시 오류 화면이 뜬다
- [ ] [앱] 주입 스크립트가 페이지 로드마다 한 번만 들어간다 (중복 주입 없음)
- [ ] [앱] 내 쇼핑몰을 추가하면 목록에 나타나고, 앱을 다시 켜도 남아 있으며, 삭제하면 사라진다
- [ ] [앱] `https://`가 아닌 주소와 이미 있는 주소는 추가되지 않는다
- [ ] [수동] 지원 쇼핑몰 각각이 실제 기기에서 열리고, 로그인·장바구니·결제 화면까지 가는지 체크리스트로 확인한다
