# 기능: 공유하기로 상품 받기

## 설명
다른 쇼핑 앱이나 브라우저에서 **공유** 버튼으로 이 앱에 상품을 보내면 분석한다. 제출 기획서의 핵심 경로였고, 인앱 브라우저를 못 쓰는 경우(다른 쇼핑 앱 사용, Play 심사에서 WebView 문제)의 대안이기도 하다.

- **링크 공유:** 받은 URL을 인앱 브라우저로 연다. 그 뒤는 인앱 브라우저 흐름과 같다.
- **이미지 공유 (스크린샷):** OCR로 글자를 읽고 → [상품 정보 구조화](../translation/product-extraction.md) → [유사 의류 검색](../compare/similar-search.md) → [비교 리포트](../compare/purchase-report.md)
- 앱 안에서 캡처를 직접 올리는 버튼도 같은 경로를 쓴다.

## 입력
- Android 공유 인텐트 (`ACTION_SEND`): `text/plain`(URL이 들어 있는 글), `image/*`
- 스크린샷 1장 (MVP는 1장)

## 출력
- 링크: 인앱 브라우저 화면
- 이미지: OCR 글자, 상품 정보 카드, 유사 의류 TOP 3, 비교 리포트

## 예외 상황
- 공유한 글에 URL이 없음: "링크를 찾지 못했어요"
- 스크린샷에서 글자를 거의 못 읽음: "글자를 읽지 못했어요. 상품 설명이 보이게 다시 캡처해 주세요"
- 스크린샷에 옷 사진이 없음: 정보 카드만 만들고 유사 검색은 하지 않는다
- OCR 신뢰도가 낮은 글자: 원문과 함께 `불확실` 표시
- 이미지 여러 장 공유: MVP는 첫 장만 쓰고 그 사실을 알려 준다

## 완료 조건
- [ ] [앱] `text/plain` 공유 인텐트에서 URL을 뽑아 인앱 브라우저로 연다 (URL 추출은 단위 테스트)
- [ ] [앱] `image/*` 공유 인텐트를 받으면 분석 화면으로 간다
- [ ] [서버] 고정 스크린샷 입력에서 OCR → 상품 정보 → TOP 3 → 리포트가 한 번에 이어진다 (OCR·LLM 가짜)
- [ ] [서버] 글자가 없는 이미지는 오류 메시지를 돌려준다
- [ ] [평가] 영어·일본어 상품 캡처로 업로드부터 결과 표시까지 시간을 재고 progress.md에 기록한다 (목표 중앙값 10초)
