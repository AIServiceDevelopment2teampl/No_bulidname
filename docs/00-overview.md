# 프로젝트 개요

> 원본 자료 (수정하지 않음): [아이디어_상세.md](../아이디어_상세.md), [추가 idea.txt](../추가%20idea.txt), 제출 기획서 `팀플기획서-12조 (1).pdf` (2026-10-14, 인공지능서비스개발II 12조)
> 서비스 이름: 미결정 (후보: ClosetLens, 옷장 AI)

## 목표
1. 해외 쇼핑몰에서 옷을 볼 때 외국어 상품 정보를 **그 자리에서 한국어로** 보여 주고, **내 옷장 속 비슷한 옷**과 비교해 구매 판단을 돕는 안드로이드 앱을 만든다.
2. 안드로이드 스튜디오(Kotlin)로 개발하고 **Google Play 스토어에 정식 출시**한다.

핵심 가치는 번역 자체가 아니라, 번역으로 이해한 상품 정보를 내 보유 의류 데이터와 연결하는 것이다.

## 대상 사용자
- 해외 쇼핑몰에서 옷을 사거나 살 생각이 있는 20~30대
- 색상·디자인이 겹치는 옷을 반복해서 사는 사람
- 영어·일본어 등의 소재·사이즈·핏 설명을 읽기 어려운 사람
- 옷에 관심이 적거나 고르는 법을 잘 모르는 사람 (AI 점원 대상)

## 핵심 원칙 (포기하지 않는 것)
1. **등록은 최대한 자동으로.** 옷을 하나씩 찍어 올리는 방식만으로는 아무도 쓰지 않는다. 주문내역 캡처, 앱에서 산 옷, 영수증으로 자동 등록하고 사진 직접 등록은 마지막 수단으로 둔다.
2. **쇼핑 흐름을 끊지 않는다.** 번역은 페이지 글자를 그 자리에서 바꾸는 방식(구글 웹 번역 방식)으로 하고, AI 점원은 화면을 가리지 않는 패널로 띄운다.
3. **사실만 말한다.** 원문에 없는 정보는 `정보 없음`으로 표기한다. 이미지 유사도를 '중복 구매 확률'로 표현하지 않는다. 구매를 권하거나 막는 단정을 하지 않는다.
4. **개인정보는 최소로만 다룬다.** 로그인·결제 화면의 내용은 읽지 않고, 사용자가 자기 데이터를 모두 지울 수 있게 한다.

## 범위
### 포함 (MVP)
- 안드로이드 앱 (Kotlin + Jetpack Compose) + 앱 안에서 쇼핑몰을 여는 인앱 브라우저
- 옷장: 사진 등록·자동 분류, 조회·필터·수정·삭제
- 옷 자동 등록: 주문내역 캡처로 일괄 등록, 앱에서 산 옷 자동 감지, 영수증 사진 등록
- 인앱 브라우저 페이지 번역: 영어·일본어 필수, 그 밖의 언어는 자동 감지로 가능한 만큼 지원
- 단위·사이즈 변환: 인치→cm, 파운드→kg, 해외 사이즈→한국 사이즈 (원문 병기)
- 상품 정보 구조화 (상품명·색상·소재·핏·사이즈·세탁)
- 공유하기로 상품 받기: 다른 앱에서 공유한 링크·스크린샷 분석 (제출 기획서 기능)
- 내 옷장 유사 의류 TOP 3 검색
- 구매 전 비교 리포트 (비슷한 점 / 다른 점 / 확인 안 된 점)
- AI 점원: 상품 질문 답변, 비교 리포트 전달, '이 옷과 어울리는 내 옷' 수준의 간단 추천
- Google Play 정식 출시

**지원 의류 종류 (MVP):** 상의·하의·아우터. 그 밖의 옷은 `기타`로 저장만 하고 성능 평가 대상에서 뺀다.

### 제외
- **카드 결제내역 연동.** 카드 내역에는 가맹점명과 금액만 있어 옷 정보를 알 수 없고, 마이데이터 API는 허가받은 사업자만 쓸 수 있다.
- 다른 쇼핑 앱 위에 겹쳐 띄우는 화면 오버레이 번역 (인앱 브라우저와 공유하기로 대체)
- 상품 이미지 속 글자 번역 (예: 이미지로 된 사이즈표) → 후속
- 전체 코디 조합 추천, 착용 빈도 통계, 체형 기반 사이즈 추천 → 후속
- iOS, 이메일(주문확인 메일) 연동 자동 등록 → 후속
- 예상 총액 계산 (상품가 + 대략적인 배송비 + 관세·부가세, 면세 한도 미국 발송 $200·그 외 $150, '참고용' 표시)과 `배송대행 필요` 쇼핑몰에서 배송대행지 업체 목록 링크 → 후속
- 배송대행 중개 (제휴 수수료, 배대지 주소 자동 입력) → 사업화할 때의 아이디어. 주소 등 개인정보 처리와 통신판매중개업 신고 같은 법적 의무가 생겨 이 프로젝트에서는 하지 않는다

## 화면 구성
하단 탭 4개: **홈 / 내 옷장 / 번역(쇼핑) / 마이**

| 화면 | 내용 |
|------|------|
| 홈 | `쇼핑하기`, `내 옷장` 진입 카드. 시안: [베이스](image/메인%20화면%28베이스%29.png), [초안](image/메인화면%20초안.png) (어느 쪽으로 갈지 미결정) |
| 쇼핑몰 목록 | `쇼핑하기`를 누르면 지원 해외 쇼핑몰 목록이 뜨고, 고르면 인앱 브라우저로 열린다. 주소 직접 입력도 가능 |
| 인앱 브라우저 | 페이지를 그 자리에서 번역한다. 번역 켜기/끄기, 원문 보기, AI 점원 버튼 |
| AI 점원 패널 | 화면 가장자리의 작은 버튼을 누르면 아래쪽 절반 패널로 열린다(초안). 위쪽에서는 쇼핑 페이지가 계속 보인다 |
| 내 옷장 | 옷 사진 격자 목록, 종류·색상 필터, 상세·수정·삭제, 등록 버튼(주문내역 캡처 / 영수증 / 사진) |
| 마이 | 설정, 내 데이터 전체 삭제, 계정 삭제, 로그아웃, 개인정보처리방침 |

## 사용자 흐름 (대표 시나리오)
1. 주문내역 캡처 몇 장으로 옷장에 옷 20벌을 등록한다. 분류가 틀린 것만 고친다.
2. 홈 → `쇼핑하기` → 일본 쇼핑몰을 고르면 인앱 브라우저로 열리고, 페이지 글자가 한국어로 바뀐다. 치수는 `76.2 cm (30 in)`처럼 함께 보인다.
3. 검은색 니트 상품 페이지에 들어가면 앱이 상품 페이지임을 알아채고, AI 점원 버튼에 "비슷한 옷 2벌 있어요" 알림이 뜬다.
4. 점원 패널을 열면 내 옷장 속 비슷한 옷 TOP 3과 비교 리포트를 보여 준다. ("보유한 검은 니트와 색·형태가 비슷합니다. 새 제품은 면 혼방이고, 기존 옷은 소재 정보가 없어 비교할 수 없습니다.")
5. "이거 세탁기 돌려도 돼?", "이거랑 어울리는 내 바지 있어?"처럼 묻는다.
6. 구매 결정은 사용자가 한다. 앱에서 결제를 마치면 "옷장에 추가할까요?" 카드가 뜨고, 한 번 누르면 등록된다.
7. 다른 쇼핑 앱을 쓰는 중이라면 상품 화면을 캡처해 이 앱으로 **공유**하면 같은 비교 결과를 받는다.

## 일정 (Sprint)
제출 기획서의 Sprint 평가 주차(8·12·15주차)에 맞춘다.

| Sprint | 주차 (추정 날짜) | 목표 |
|--------|------------------|------|
| 1차 | 8주차 (10/19~10/25) | UI/UX 설계, 안드로이드 프로젝트 구성, 기술 검증, Play Console 계정 |
| - | 9~11주차 (10/26~11/15) | 기능 1~8. **11주차 안에 첫 빌드를 비공개 테스트에 올리고 테스터 12명 참여 시작** |
| 2차 | 12주차 (11/16~11/22) | AI 서버 API 구축·앱 연동, 공유하기, 비교 리포트 |
| - | 13~14주차 (11/23~12/6) | AI 점원, 자동 등록, 프로덕션 출시 신청 |
| 3차 | 15주차 (12/7~12/13) | Play 스토어 정식 출시, AI 서버 배포, 사용자 평가 |

## 성공 지표 (계획 단계 목표치, 측정 결과 아님)
| 항목 | 측정 방법 | 목표 |
|------|-----------|------|
| 옷 종류 분류 | 사람이 라벨링한 의류 100장과 비교 | 정확도 85% 이상 |
| 유사 의류 검색 | 사람이 고른 정답 세트의 Recall@3 | 80% 이상 |
| 상품 정보 추출 | 검증용 상품 페이지·캡처 30~50개의 필수 필드 정확도 | 90% 이상 |
| 번역 가독성 | 사용자 평가 5점 척도 | 평균 4점 이상 |
| 페이지 번역 속도 | 페이지 로드 후 첫 화면 번역 완료까지 | 중앙값 3초 이내 (초안) |
| 비교 결과 속도 | 상품 인식부터 TOP 3·리포트 표시까지 | 중앙값 10초 이내 |
| 자동 등록 비율 | 테스트 사용자 옷장 중 사진 직접 등록이 아닌 경로로 들어온 비율 | 측정 후 기록 |
| 실제 효용 | 미사용/사용 시 비교 소요 시간·설문 | 시간 단축 및 유용성 확인 |
